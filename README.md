# Elderhub: Family Care Log

Marketing and legal pages for the iOS app **Elderhub: Family Care Log**, served
by GitHub Pages at <https://jackwallner.github.io/elderhub/>.

The App Store listing and the app's own Settings screen both link here, so the
paths are load-bearing:

| Page | Path |
|---|---|
| Home | `/elderhub/` |
| Privacy policy | `/elderhub/privacy-policy.html` |
| Consumer Health Data Privacy Policy (WA MHMDA, NV SB 370) | `/elderhub/consumer-health-data.html` |
| Terms of use | `/elderhub/terms.html` |
| Support | `/elderhub/support.html` |

Pages serves from `main` / `docs`. The source of truth for these files is
`~/elderhub/docs/`; this repo is the published copy.
