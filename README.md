# Med List: Family Meds

Marketing and legal pages for the iOS app **Med List: Family Meds**, served by
GitHub Pages at <https://jackwallner.github.io/medlist/>.

The App Store listing and the app's own Settings screen both link here, so the
paths are load-bearing:

| Page | Path |
|---|---|
| Home | `/medlist/` |
| Privacy policy | `/medlist/privacy-policy.html` |
| Consumer Health Data Privacy Policy (WA MHMDA, NV SB 370) | `/medlist/consumer-health-data.html` |
| Terms of use | `/medlist/terms.html` |
| Support | `/medlist/support.html` |

Pages serves from `main` / `docs`. The source of truth for these files is
`~/aging/docs/site/`; this repo is the published copy.
